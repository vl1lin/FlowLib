# 7. Определение градиента давления

Градиент давления вычисляет корреляция (`ICorrelation`) методом `calc(state)`. Результат —
`CorrelationResult`.

## Что возвращает расчёт

| Поле | Единица | Смысл |
|---|---|---|
| `pattern` | — | Режим течения (`FlowPattern`), определённый моделью режима |
| `holdup` | — | Истинное объёмное содержание жидкости H_L, от 0 до 1 |
| `dpdl_pa_m` | Па/м | Полный градиент −dp/dL; положительное значение — давление падает по потоку |
| `dpdl_gravity_pa_m` | Па/м | Гравитационная составляющая |
| `dpdl_friction_pa_m` | Па/м | Составляющая трения |
| `dpdl_acceleration_pa_m` | Па/м | Составляющая ускорения |
| `details` | — | Промежуточные величины с единицами в именах ключей |

Результат неизменяем и проверяется при создании:

- `holdup` лежит в диапазоне 0…1;
- `dpdl_pa_m` равен сумме трёх составляющих с относительной точностью 1e-10.

## Знак и направление

Градиент `dpdl_pa_m` — это **−dp/dL**: потеря давления на единицу длины. Для восходящего потока
гравитационная составляющая положительна (столб жидкости давит), для нисходящего — отрицательна
(давление растёт благодаря гравитации). Расстояние L отсчитывается вдоль потока.

Чтобы получить перепад давления на участке длиной L, умножьте градиент на длину; для длинных
участков с меняющимися свойствами рассчитывайте градиент по сечениям (профиль давления) и
интегрируйте.

## Составляющие градиента

### Гравитационная

ρ·g·sinθ, где ρ — плотность смеси с учётом истинного содержания жидкости (в разных корреляциях
берётся плотность «с проскальзыванием» или плотность ядра потока). Для горизонтальной трубы она
равна нулю.

### Трения

Определяется коэффициентом трения f (по Moody/Colebrook с шероховатостью ε/d либо по специальным
формулам корреляции) и скоростью смеси. В кольцевом режиме учитывается трение ядра потока.

### Ускорения

Учитывается через знаменатель 1 − Ek, где кинетическое число Ek = ρ·v_m·v_sg/p:

−dp/dL = (гравитация + трение)/(1 − Ek).

В результате возвращаются гравитационная и фрикционная части **до** деления на (1 − Ek), а
составляющая ускорения равна разности между полным градиентом и их суммой.

Какие корреляции учитывают ускорение:

| Корреляция | Режимы, где учитывается ускорение | Флаг отключения |
|---|---|---|
| `beggs_brill` | Все режимы | `include_acceleration` |
| `mukherjee_brill` | BUBBLE, SLUG, ANNULAR (расслоённый — без ускорения) | `include_acceleration` |
| `hasan_kabir` | Только ANNULAR (знаменатель 1 − ρ_c·v_g²/p) | `include_acceleration` |
| `ansari` | Не учитывается | — |

При Ek ≥ 1 (газ высокой скорости при малом давлении) знаменатель 1 − Ek перестаёт быть
положительным, и расчёт завершается `ConvergenceError`. Тогда проверьте входные данные или
отключите флаг `include_acceleration`.

## Истинное содержание жидкости

`holdup` — доля сечения трубы, занятая жидкостью, с учётом проскальзывания фаз. Не путайте её с
расходным содержанием жидкости λ_L = v_sl/(v_sl + v_sg): из-за проскальзывания газ движется быстрее
жидкости, поэтому при подъёме holdup обычно больше λ_L.

Стремление к однофазному газу при v_sl → 0 корреляциями не гарантируется (см.
[ограничение](05-correlations/README.md#ограничение-предел-сухого-газа-v_sl--0)).

В однофазных пределах: чистая жидкость — `holdup = 1`, чистый газ — `holdup = 0`; градиент
рассчитывается как для однофазного потока.

## Промежуточные величины `details`

Набор ключей зависит от корреляции и режима; ключи содержат единицы (например, `_m_s`, `_pa_s`).
Они нужны для диагностики и сверки: скорости фаз, безразмерные числа, число Рейнольдса, коэффициент
трения, длины и доли пробковой ячейки (Ansari). Описание ключей — в страницах конкретных
[корреляций](05-correlations/README.md).

## Сборка профиля давления

Корреляции рассчитывают градиент для **одного** сечения. Профиль давления вдоль трубы получается
повторными расчётами:

1. В каждом сечении задаются давление, температура и расходы; по ним находятся плотности,
   вязкости, приведённые скорости (подготовка свойств флюидов остаётся за вызывающим кодом).
2. Для сечения строится `FlowState`, вычисляется градиент.
3. Давление на следующем сечении получают, вычитая из текущего произведение градиента на шаг по
   длине (для восходящего потока); шаг выбирают достаточно малым, чтобы свойства внутри шага
   менялись слабо.

Примеры: профиль давления по участкам скважины —
[`06_well_profile.py`](../examples/06_well_profile.py), таблица «угол × скорость газа» —
[`07_sweep_table.py`](../examples/07_sweep_table.py).

## Ошибки и предупреждения

См. [раздел 2](02-validation-and-errors.md): `ValidationError` для входа, `ConvergenceError` (в том
числе Ek ≥ 1), `UnsupportedPatternError` для несовместимой пары «корреляция + модель режима»,
`OutOfRangeWarning` при расчёте вне области применимости.
