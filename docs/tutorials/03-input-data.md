# 3. Входные данные: `FlowState`

Каждый расчёт — для **одного сечения** трубы: `FlowState` описывает локальное состояние потока.
Профиль по длине получают повторными расчётами для разных сечений (см.
[раздел о градиенте давления](07-pressure-gradient.md)). Все величины — в СИ.

## Поля

| Поле | Единица | Допустимо | По умолчанию | Смысл |
|---|---|---|---|---|
| `v_sl_m_s` | м/с | ≥ 0 | — | Приведённая скорость жидкости: расход жидкости, делённый на площадь сечения |
| `v_sg_m_s` | м/с | ≥ 0 | — | Приведённая скорость газа: расход газа при условиях в сечении, делённый на площадь |
| `rho_l_kg_m3` | кг/м³ | > 0 | — | Плотность жидкости |
| `rho_g_kg_m3` | кг/м³ | > 0 | — | Плотность газа |
| `mu_l_pa_s` | Па·с | > 0 | — | Динамическая вязкость жидкости |
| `mu_g_pa_s` | Па·с | > 0 | — | Динамическая вязкость газа |
| `sigma_n_m` | Н/м | > 0 | — | Поверхностное натяжение на границе жидкость–газ |
| `d_m` | м | > 0 | — | Внутренний диаметр трубы; для затрубья — внутренний диаметр обсадной колонны |
| `d_t_m` | м | ≥ 0 | 0 | Наружный диаметр НКТ; 0 означает обычную трубу (не затрубье) |
| `eps_m` | м | ≥ 0 | 0 | Абсолютная шероховатость стенки |
| `theta_deg` | градус | −90…90 | — | Угол от горизонтали: > 0 — подъём, < 0 — спуск |
| `p_pa` | Па | > 0 | — | Давление в сечении |

Условия согласованности (проверяются при создании, см.
[раздел о проверке данных](02-validation-and-errors.md)): ρ_L > ρ_g; d_t < d; ε < d;
v_sl + v_sg > 0.

## Приведённые скорости

Приведённая (поверхностная) скорость фазы — расход фазы, делённый на полную площадь сечения трубы,
как если бы эта фаза текла одна. Скорость смеси v_m = v_sl + v_sg. Расходы газа и жидкости
необходимо привести к **условиям в сечении** (давление и температура в точке расчёта), а не к
стандартным.

## Угол

- `theta_deg = 0` — горизонтальная труба;
- `theta_deg = 90` — вертикальный подъём (добыча по скважине);
- `theta_deg = −90` — вертикальный спуск (нагнетание);
- положительные значения — подъём вверх по потоку, отрицательные — спуск.

Некоторые модели ограничены по углу (Hasan–Kabir и Ansari созданы для подъёма; Mukherjee–Brill и
Beggs–Brill описывают весь диапазон, см. [раздел о корреляциях](05-correlations/README.md)).

## Давление

Давление используется для расчёта слагаемого ускорения (Ek = ρ_s·v_m·v_sg/p) и для выбора
границы slug/churn в модели режима Hasan–Kabir при включённом флаге `porteous_low_pressure`.
Для остальных расчётов оно прямого влияния не оказывает: свойства флюидов (плотности, вязкости)
вы задаёте сами.

## Затрубье

Если `d_t_m > 0`, поток рассматривается как течение в затрубном пространстве: `d_m` — внутренний
диаметр обсадной колонны, `d_t_m` — наружный диаметр НКТ. Учёт кольцевого сечения реализован в
корреляции и модели режима Hasan–Kabir; остальные модели используют `d_m` без учёта `d_t_m`.

## Шероховатость

`eps_m` задаёт абсолютную шероховатость. Коэффициент трения считается по Moody/Colebrook с учётом
относительной шероховатости ε/d, кроме случаев, когда флаг настроек переключает модель на гладкую
формулу (подробности — в разделах о корреляциях и моделях режима).

Относительная шероховатость ε/d в формуле Colebrook ограничена сверху значением 0.05 — верхней
границей диаграммы Moody. Если в какой-то фазе расчёта ε/d оказывается выше (например, у газовой
фазы расслоённого потока с очень малым сечением), коэффициент трения считается при 0.05 и
выдаётся `OutOfRangeWarning`; расчёт при этом не прерывается.

## Однофазные пределы

- `v_sl_m_s = 0` — течёт только газ; режим `SINGLE_PHASE_GAS`;
- `v_sg_m_s = 0` — течёт только жидкость; режим `SINGLE_PHASE_LIQUID`.

Обе скорости одновременно равными нулю быть не могут.

## Неизменяемость

`FlowState` неизменяем (`frozen`). Для расчёта в другом сечении создавайте новое состояние с
нужными значениями полей.
