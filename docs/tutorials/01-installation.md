# 1. Установка

## Требования

- Python 3.11 или новее (`requires-python = ">=3.11"`); в репозитории закреплена версия 3.14
  (файл `.python-version`).
- Менеджер окружения [uv](https://docs.astral.sh/uv/). Зависимости ставятся только через `uv`,
  не через `pip install`.
- Зависимости времени выполнения: `numpy>=2.0`, `pydantic>=2`, `scipy>=1.13`.
- Зависимости разработки (группа `dev`): `pyright`, `pytest`, `pytest-cov`, `ruff`.

Система сборки пакета — `uv_build`. Исходный код лежит в `src/correlations`; пакет типизирован
(есть маркер `py.typed`), поэтому проверки типов в вашем проекте видят аннотации библиотеки.

## Установка из исходников

Выполняется в корне репозитория:

```bash
uv sync
```

Команда создаёт виртуальное окружение `.venv` и устанавливает пакет вместе с зависимостями и
группой `dev`.

## Проверка окружения (Windows, PowerShell)

Перед установкой других пакетов проверьте, какой интерпретатор Python используется:

```powershell
Get-Command python
```

Если выбран глобальный интерпретатор, а не `.venv`, активируйте окружение:

```powershell
. .\.venv\Scripts\Activate.ps1
```

## Проверка работоспособности

Все проверки сразу (ruff, форматирование, pyright, тесты):

```bash
uv run python check.py
```

Отдельные шаги:

```bash
uv run pytest -q
uv run ruff check --fix .
uv run ruff format .
uv run pyright
```

Итог `check.py` — строка «Все проверки пройдены» и код возврата 0; при первой неуспешной проверке
скрипт останавливается и возвращает её код.

## Покрытие тестами

Опция `pytest --cov` на Python 3.14 не работает из-за несовместимости с numpy. Используйте
`coverage` напрямую:

```bash
uv run coverage run --source=src/correlations/core,src/correlations/flow_models,src/correlations/models -m pytest -q -p no:warnings
uv run coverage report -m
```

## Добавление новых зависимостей

Новые зависимости добавляются командой `uv add <пакет>`; перед этим проверьте интерпретатор
(см. выше).
