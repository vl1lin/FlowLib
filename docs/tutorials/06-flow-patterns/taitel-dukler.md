# Модель режимов Taitel–Dukler (`taitel_dukler`)

Механистическая модель режимов для горизонтальных и близких к ним труб. Основана на равновесном
расслоённом потоке и условиях его потери устойчивости.

## Источник

Taitel Y., Dukler A.E., 1976, AIChE J. 22(1), 47–55, ур. (6)–(16), (25), (30), (36), (37).

## Режимы

STRATIFIED_SMOOTH, STRATIFIED_WAVY, ANNULAR, DISPERSED_BUBBLE, INTERMITTENT.

## Схема расчёта

Угол в статье α = −θ (α > 0 — спуск); знак учтён в параметре Y.

1. Параметр Мартинелли X² = (dp/dx)_LS/(dp/dx)_GS (ур. 8) и параметр Y (ур. 9) — по градиентам
   однофазных потоков (формулы Fanning Taitel–Dukler переводятся в коэффициент Darcy умножением на 4).
2. Равновесный уровень жидкости h̃_L — наименьший корень уравнения (7).
3. Критерий Кельвина–Гельмгольца (25) < 1 — расслоённый поток. Если выполнен критерий волн (30),
   режим STRATIFIED_WAVY, иначе STRATIFIED_SMOOTH (коэффициент s = 0.01).
4. Иначе: h̃_L < 0.5 — ANNULAR; при h̃_L ≥ 0.5 критерий (36) T² ≥ 8·Ã_G/(S̃_i·ũ_L²·(ũ_L·D̃_L)^−n)
   даёт DISPERSED_BUBBLE, иначе INTERMITTENT.

## Флаги

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `laminar_switch` | `True` | Коэффициенты C, n трения выбираются по фактическому числу Рейнольдса каждой фазы; `False` — всегда турбулентные (для сверки с картой Fig. 4) |
| `use_moody_friction` | `False` | Градиенты однофазных потоков по Colebrook с шероховатостью вместо гладких формул 0.046·Re^−0.2 и 16/Re |

## Расхождения и допущения

- В ур. (25) напечатано ũ_G, принято ũ_G² (реализовано в `stratified.kelvin_helmholtz_parameter`).
- При `laminar_switch` ламинарность фазы определяется по числу Рейнольдса с фактической скоростью и
  гидравлическим диаметром (6), критическое значение 2000 (Taitel–Dukler порог не задают).
  Перебираются комбинации «турбулентный–турбулентный, турбулентный–ламинарный, ламинарный–
  турбулентный, ламинарный–ламинарный»; берётся первая согласованная, иначе
  «турбулентный–турбулентный».

## Ключи `details`

`x`, `y`, `h_l_over_d`, `holdup_stratified`, `f`, `k`, `t`, `m_gas`, `n_liquid`.

## Совместимость

Корреляции работают с режимами INTERMITTENT, ANNULAR и DISPERSED_BUBBLE частично (см. матрицу в
[разделе 5](../05-correlations/README.md)); расслоённые режимы ни одной корреляцией не
поддерживаются.
