# Модель режимов Ansari (`ansari_fp`)

Механистическая модель режимов для вертикального и наклонного подъёма. Содержит также решение для
плёнки в кольцевом режиме, которое использует корреляция Ansari.

## Источник

Ansari A.M., Sylvester N.D., Sarica C., Shoham O., Brill J.P., 1994, SPE Production & Facilities
9(2), 145–152, ур. (2)–(15), (69)–(72), (74)–(85), (94)–(102).

## Режимы

BUBBLE, DISPERSED_BUBBLE, SLUG, ANNULAR. Churn отдельно не выделяется — входит в SLUG.

## Схема расчёта

Порядок проверок взят из Примера 4.9 (в статье не задан):

1. **DISPERSED_BUBBLE.** Левая часть (4) не меньше 0.725 + 4.15·(v_sg/v_m)^0.5 (f — по Moody для
   числа Рейнольдса без проскальзывания) и v_sg < 3.17·v_sl (5).
2. **ANNULAR.** v_sg > 3.1·[g·σ·Δρ/ρ_g²]^0.25 (6) и не выполнено H_LF + λ_LC·A_C/A > 0.12 (12), где
   толщина плёнки δ берётся как δ_min из ур. (8) (флаг `bridging_with_delta_min`) либо как δ
   из ур. (96).
3. **BUBBLE.** d > d_min = 19.01·[Δρ·σ/(ρ_L²·g)]^0.5 и v_sg < v_sl/3 + 0.25·v_s (2); при
   `bubble_slug_sin_theta` скорость v_s умножается на sinθ, как у Barnea [4].
4. Иначе — SLUG.

### Плёнка в кольцевом режиме

Определяются доля уноса F_E (71)–(72), доля жидкости в ядре λ_LC, плотность и вязкость ядра,
градиенты однофазных потоков (79)–(80), (87)–(88), отношение f_F/f_SL по числу Рейнольдса плёнки
(74)–(76) (или 1 при `ff_over_fsl_unity`), параметры X_M² (9), Y_M (10), Z (84)/(85); толщина
плёнки δ — корень ур. (96).

## Флаги

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `bridging_with_delta_min` | `True` | В критерии (12) берётся δ_min из (8) (текст статьи); `False` — δ из (96) (Пример 4.9) |
| `bubble_slug_sin_theta` | `False` | 0.25·v_s·sinθ в ур. (2), как у Barnea [4]; для наклонных скважин |
| `ff_over_fsl_unity` | `False` | f_F/f_SL = 1 без итерации по числу Рейнольдса плёнки; быстрый расчёт и Пример 4.9 |

## Расхождения и допущения

- Исправление опечатки: в ур. (85) показатель (ρ_L/ρ_g)^(1/3) (реализовано в
  `core.annular.whalley_hewitt_z`).
- Критерий «δ < δ_min» отдельно не применяется: статья проверяет только (12), а δ_min лишь
  определяет H_LF.
- Если корня ур. (8) нет, в (12) берётся δ из (96). Если нет корня ур. (96), плёнка не определена и
  режим не кольцевой.
- Корни (96) и (8) ищутся на сетке по ln δ (δ от 1e-9 до 0.5); при больших v_sg плёнка очень
  тонкая. Полюс правой части (8) при 4δ(1 − δ) = 2/3 отбрасывается.
- Эталоны плёнки из ТЗ воспроизводятся только при `ff_over_fsl_unity=True`.

## Ключи `details`

`d_min_m`, `db_left`, `db_right` (две части критерия (4)), `v_sg_annular_m_s`,
`v_sg_bubble_slug_m_s`.
