# Карта режимов Mukherjee–Brill (`mukherjee_brill_fp`)

Эмпирическая карта режимов для наклонных труб — восходящих и нисходящих. Границы заданы через
безразмерные числа Данса–Роса и зависят от угла.

## Источник

Mukherjee H., Brill J.P., 1985, Int. J. Multiphase Flow 11(3), 299–315, ур. [1]–[4], рис. 16.

## Режимы

BUBBLE, SLUG, ANNULAR, STRATIFIED.

## Схема расчёта

Блок-схема рис. 16 статьи (θ > 0 — подъём):

1. Числа: скоростные N_Lv и N_gv, число свойств жидкости N_L (с g).
2. Если N_gv больше границы кольцевого режима N_gvSM [2] — ANNULAR (граница не зависит от угла).
3. Подъём (θ > 0): N_Lv больше N_LvBS [1] — BUBBLE, иначе SLUG.
4. Спуск круче 30° (θ ≤ 0 и |θ| > 30°): N_gv больше N_gvBS [3] — тогда при N_Lv больше N_LvST [4]
   SLUG, иначе STRATIFIED; если N_gv не больше N_gvBS — BUBBLE.
5. Спуск пологий (θ ≤ 0 и |θ| ≤ 30°): N_Lv больше N_LvST [4] — тогда при N_gv больше N_gvBS [3]
   SLUG, иначе BUBBLE; если N_Lv не больше N_LvST — STRATIFIED.

## Флаги

Флагов нет.

## Расхождения с источником

- В уравнении [3] оригинала напечатано «sin 0»; принято sinθ (исправление опечатки по ТЗ).
- Член −0.017·N_gv в [4] линейный в обоих оригиналах — не изменяется.

## Ключи `details`

`n_lv`, `n_gv`, `n_l` и границы `n_gv_sm`, `n_lv_bs`, `n_gv_bs`, `n_lv_st` — в зависимости от
пройденной ветви блок-схемы.

## Совместимость

Родная модель режима корреляции [Mukherjee–Brill](../05-correlations/mukherjee-brill.md). Режим
STRATIFIED не принимается Hasan–Kabir и Ansari.
