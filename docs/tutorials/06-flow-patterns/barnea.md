# Унифицированная модель режимов Barnea (`barnea`)

Механистическая модель режимов для всего диапазона наклонов от −90° до +90°: объединяет критерии
для горизонтальных, наклонных и вертикальных труб в одну блок-схему.

## Источники

- Barnea D., 1987, Int. J. Multiphase Flow 13(1), 1–12, ур. [1]–[23], Fig. 6 — модель.
- Barnea D., 1986, IJMF 12(5) — дополнительный источник, указанный в ТЗ.

## Режимы

DISPERSED_BUBBLE, BUBBLE, SLUG, CHURN, ANNULAR, STRATIFIED_SMOOTH, STRATIFIED_WAVY,
ELONGATED_BUBBLE.

## Схема расчёта

Fig. 6 статьи; θ = β > 0 — подъём.

1. **Дисперсно-пузырьковый.** Максимальный диаметр пузыря d_max < d_C ([5]–[7]) и расходное
   газосодержание α_ns < 0.52 — DISPERSED_BUBBLE.
2. **Расслоённый** (при cosβ ≠ 0). Определяется равновесный уровень жидкости h̃_L. Если критерий
   устойчивости [9] < 1 и не выполнен критерий [14] (переход к кольцевому) — расслоённый поток:
   при выполнении [20] или [23] — STRATIFIED_WAVY, иначе STRATIFIED_SMOOTH. При |β| = 90°
   расслоённый режим невозможен.
3. **Кольцевой.** Уравнение плёнки [15] (наименьший корень α_L). Если плёнка неустойчива [16] или
   перемкнута [17] — переход к шагу 4, иначе ANNULAR.
4. **Пузырьковый.** Возможен, если D > D_crit [1] и |β| ≥ β_crit [2]: тогда v_sg ниже границы
   [4] — BUBBLE, иначе шаг 6. Невозможен — шаг 5.
5. **Вытянутые пузыри.** Содержание газа в пробке α_s по [18]; при α_s = 0 и β = 0 —
   ELONGATED_BUBBLE.
6. **Пробка или churn.** α_s ≤ 0.52 — SLUG, иначе CHURN.

## Критерий [14] и флаг `friction_ratio_as_published`

Критерий [14] определяет переход «расслоённый → кольцевой»:
Z ≥ 2·(Ã_L/Ã)²·(1 − h̃)·f_LS/f_L. Отношение f_LS/f_L можно считать двумя способами.

| Значение флага | Формула | Происхождение |
|---|---|---|
| `True` (по умолчанию) | f_LS/f_L = (D̃_L·Ũ_L)^−n; n = 0.2 при турбулентном течении жидкости, n = 1 при ламинарном | Текст статьи; значения n подтверждены по статье |
| `False` | f(Re_LS)/f(Re_L) по выбранной модели трения | Прежняя реализация, учитывает шероховатость |

Для гладкой трубы с f ∝ Re^−n определение f_LS/f_L даёт (D̃_L·Ũ_L)^(+n), то есть запись статьи
обратна определению; по решению проекта расчёт ведётся по тексту статьи. Различие между
вариантами — множитель (D̃_L·Ũ_L)^(2n); при n = 0.2 он равен 1.89 / 1.63 / 1.49 / 1.32 / 1.20 при
h̃_L = 0.1 / 0.2 / 0.3 / 0.5 / 0.7. Режим меняется только в узкой области вблизи перехода
«расслоённый – кольцевой». На проверенной сетке воздух–вода (d = 2.54, 5.1 и 10 см, β = 0°, −5°, −30°, −80°) различия
найдены только для нисходящей трубы, близкой к вертикали (β = −80°); сетка грубая, поэтому
оценка нижняя.

**Допущение:** режим течения (значение n) выбирается по числу Рейнольдса слоя жидкости
Re_L = ρ_L·U_L·D_L/μ_L: течение ламинарное при Re_L < 2000, иначе турбулентное. В статье этот
выбор не уточнён. Использованное отношение доступно в `details["f_ls_over_f_l"]`.

## Исправления опечаток и допущения

- [5]: показатели 3/5 и −2/5 (напечатано 3/2 и −2/3).
- [15]: (1 − α_L)^(5/2) (напечатано 3/2).
- Fig. 6, ветка L: «Condition [14]» (напечатано [4]).
- [19]: g·cosβ (напечатано ρ·cosβ).
- Критерий миграции пузырей [2]: d = d_CD, γ = 1.3, C_L = 0.8 (допущение).
- При нескольких корнях [15] берётся наименьший; если корня [15] нет — переход к шагу 4.

## Ключи `details`

`d_max_m`, `d_critical_m`, `alpha_ns`, `alpha_s`; при расчёте расслоённой ветви — `h_l_over_d`,
`f_ls_over_f_l` (если [9] < 1); при расчёте плёнки — `alpha_l_film`, `film_unstable`,
`film_blocked`.

## Совместимость

Модель выдаёт расслоённые режимы и ELONGATED_BUBBLE, которые не поддерживает ни одна из четырёх
корреляций (см. матрицу в [разделе 5](../05-correlations/README.md)). Для остальных режимов
подходят Hasan–Kabir и Ansari.
