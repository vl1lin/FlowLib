# Руководство по использованию пакета `correlations`

Полное руководство по расчёту режима течения, истинного содержания жидкости и градиента давления
газожидкостного потока в трубах и скважинах. Все величины в пакете — в СИ.

Запускаемые примеры кода — в каталоге [`docs/examples/`](../examples/README.md).

## Основные соглашения

- Единицы — СИ; единицы указаны в именах полей (`v_sl_m_s`, `d_m`, `p_pa`, …), угол — в градусах.
- Угол `theta_deg` отсчитывается от горизонтали; положительный — подъём (вверх), вертикальный
  подъём — 90°, спуск — отрицательные значения.
- Градиент давления `dpdl_pa_m` — это −dp/dL: положительное значение означает падение давления
  по потоку.
- Настройки моделей — только булевы флаги; значения по умолчанию соответствуют оригинальной статье.
- Расхождения реализации с источником всегда описаны в docstring соответствующего модуля и в
  разделах этого руководства.
