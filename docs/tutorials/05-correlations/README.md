# 5. Корреляции

Корреляция (`ICorrelation`) выполняет полный расчёт для одного сечения трубы: определяет режим
течения (через модель режима), истинное содержание жидкости и градиент давления.

| Корреляция | Имя в реестре | Область применения | Модель режима по умолчанию |
|---|---|---|---|
| [Beggs–Brill](beggs-brill.md) | `beggs_brill` | Наклонные трубы любого угла, эмпирическая | `beggs_brill_map` |
| [Mukherjee–Brill](mukherjee-brill.md) | `mukherjee_brill` | Наклонные трубы любого угла, режимы с поправками на угол | `mukherjee_brill_fp` |
| [Hasan–Kabir](hasan-kabir.md) | `hasan_kabir` | Вертикальный подъём в трубе и затрубье, механистическая | `hasan_kabir_fp` |
| [Ansari](ansari.md) | `ansari` | Подъём (вертикальный и наклонный), механистическая | `ansari_fp` |

Приоритет проекта — механистические модели (Hasan–Kabir, Ansari, а также модели режима Barnea и
Taitel–Dukler). Эмпирические Beggs–Brill и Mukherjee–Brill реализованы для сверки и как опорные
методы.

## Общая схема расчёта

Для любой корреляции расчёт идёт в таком порядке:

1. Проверка входных данных (`FlowState`, см. [раздел 2](../02-validation-and-errors.md)).
2. Определение режима течения внедрённой моделью режима. Для однофазных пределов
   (`v_sl = 0` или `v_sg = 0`) режим — `SINGLE_PHASE_GAS` / `SINGLE_PHASE_LIQUID`.
3. Расчёт истинного содержания жидкости H_L по формулам, выбранным для этого режима.
4. Расчёт составляющих градиента давления: гравитационной, трения и (если предусмотрено)
   ускорения.
5. Сборка `CorrelationResult` с проверкой, что полный градиент равен сумме составляющих.

## Внедрение модели режима

Режим определяет не корреляция, а внедряемая модель режима. Корреляцию можно связать с другой
моделью: в реестре — аргументом `flow_model` (имя или готовый экземпляр), при прямом создании —
вторым аргументом конструктора. Это позволяет, например, считать Hasan–Kabir или Ansari по
карте Barnea.

Подстановка осмысленна только если корреляция умеет считать режимы, которые выдаёт модель режима.
Иначе возникает `UnsupportedPatternError`.

### Какие режимы принимает каждая корреляция

| Корреляция | Принимаемые режимы | Примечание |
|---|---|---|
| `beggs_brill` | SEGREGATED, INTERMITTENT, DISTRIBUTED, TRANSITION | TRANSITION возможен только при `revised_map` (нужны границы L2, L3 из карты Beggs–Brill) |
| `mukherjee_brill` | BUBBLE, SLUG, ANNULAR, STRATIFIED | Режим STRATIFIED_SMOOTH / STRATIFIED_WAVY не принимается |
| `hasan_kabir` | BUBBLE, DISPERSED_BUBBLE, SLUG, CHURN, ANNULAR | |
| `ansari` | BUBBLE, DISPERSED_BUBBLE, SLUG, CHURN, ANNULAR | CHURN считается как SLUG |

Однофазные режимы принимаются всеми корреляциями.

### Совместимость корреляций и моделей режима

Проверено расчётом на сетке воздух–вода (v_sl 0.001…3 м/с, v_sg 0.01…30 м/с, d = 2.54 и 10 см,
θ = −80°…90°, p = 0.1 МПа). «Всегда» — все точки сетки рассчитаны без
`UnsupportedPatternError`; «частично» — на части точек модель режима выдаёт режим, который
корреляция не умеет считать; «нет» — на всей сетке.

| Модель режима | `beggs_brill` | `mukherjee_brill` | `hasan_kabir` | `ansari` |
|---|---|---|---|---|
| `beggs_brill_map` | всегда (родная) | нет | нет | нет |
| `mukherjee_brill_fp` | нет | всегда (родная) | частично (нет STRATIFIED) | частично (нет STRATIFIED) |
| `hasan_kabir_fp` | нет | частично (нет CHURN, DISPERSED_BUBBLE) | всегда (родная) | всегда |
| `ansari_fp` | нет | частично (нет DISPERSED_BUBBLE) | всегда | всегда (родная) |
| `barnea` | нет | частично (нет STRATIFIED_*, CHURN, ELONGATED_BUBBLE, DISPERSED_BUBBLE) | частично (нет STRATIFIED_*, ELONGATED_BUBBLE) | частично (нет STRATIFIED_*, ELONGATED_BUBBLE) |
| `taitel_dukler` | почти нет | почти нет | частично (нет STRATIFIED_*, INTERMITTENT) | частично (нет STRATIFIED_*, INTERMITTENT) |

Практические выводы:

- Beggs–Brill работает только с картой Beggs–Brill: его режимы (SEGREGATED, INTERMITTENT,
  DISTRIBUTED) в других моделях не определяются.
- Hasan–Kabir и Ansari взаимозаменяемы по картам `hasan_kabir_fp` и `ansari_fp`, так как у них
  одинаковый набор режимов.
- Расслоённые режимы (STRATIFIED_SMOOTH, STRATIFIED_WAVY), выдаваемые `barnea` и
  `taitel_dukler`, ни одной из четырёх корреляций не поддерживаются — расчёт по таким картам
  возможен только в области, где режим не расслоённый.
- Результаты в точках, где корреляция и модель режима совместимы, зависят от пары: итоговое
  значение градиента определяется формулами корреляции для режима, выданного картой.

## Ограничение: предел сухого газа (v_sl → 0)

Модели не гарантируют плавного перехода к однофазному газу при стремлении расхода жидкости к
нулю. Точный нуль (`v_sl_m_s = 0`) обрабатывается отдельно как `SINGLE_PHASE_GAS`, а при любом
малом ненулевом значении расчёт идёт по формулам корреляции, и результат может заметно отличаться
от газового.

Воздух–вода, 0.1 МПа, v_sg = 5 м/с, d = 2.5 см, v_sl = 10⁻⁸ м/с — отношение градиента к градиенту
чистого газа:

| Корреляция | Градиент / газовый | H_L | Комментарий |
|---|---|---|---|
| `mukherjee_brill` | 1.00 | 0.000 | Сходится к газу (кольцевой режим) |
| `beggs_brill` | 1.19 (при 10⁻⁶ — 1.42) | 0.000 | Сходится медленно: H_L ∝ λ^0.48 |
| `hasan_kabir` | 92.4 | 0.156 | CHURN: f_g не превышает ≈ 0.85 |
| `ansari` | 28.4 | 0.192 | SLUG: ограничена доля газового пузыря |

Причина — в самих алгоритмах, а не в реализации: в пробковом и пульсирующем режимах газосодержание
ограничено моделью дрейфа, а граница кольцевого режима (Hasan–Kabir ур. 13, Ansari ур. 6) зависит
только от скорости газа. Поэтому для практически сухого газа:

- при отсутствии жидкости задавайте `v_sl_m_s = 0` — будет выполнен однофазный расчёт;
- при очень малых расходах жидкости не используйте `hasan_kabir` и `ansari` — они дают заметно
  завышенные градиент и H_L; предпочтительнее `mukherjee_brill` или `beggs_brill`;
- при высоком давлении и малой жидкости `ansari` в режиме ANNULAR может дать толстую плёнку
  (H_L около 0.8): критерий перемыкания (12) в статье вычисляется по минимальной толщине плёнки
  δ_min, а градиент — по толщине δ из ур. (96) (флаг `bridging_with_delta_min`).

Адаптация алгоритмов Hasan–Kabir и Ansari для сухого газа — предмет отдельного исследования.

## Типичные ошибки и предупреждения

| Ситуация | Что происходит |
|---|---|
| Режим вне набора корреляции | `UnsupportedPatternError` (см. таблицу выше) |
| Слагаемое ускорения Ek ≥ 1 (высокоскоростной газ при малом давлении) | `ConvergenceError`: знаменатель 1 − Ek не положителен. Флаг `include_acceleration=False` отключает ускорение |
| Расчёт вне области применимости формулы | `OutOfRangeWarning` (например, Hasan–Kabir при θ ≠ 90°) |

Флаги настроек всех корреляций описаны в
[README проекта](../../../README.md) и доступны через `describe_correlation(name)`.
