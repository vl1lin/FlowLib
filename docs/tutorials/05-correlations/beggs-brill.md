# Корреляция Beggs–Brill (`beggs_brill`)

Эмпирическая корреляция для течения газожидкостной смеси в трубах любого наклона. Режим течения
определяется по карте для горизонтальной трубы и нужен только для выбора коэффициентов
истинного содержания жидкости.

## Источники

- Beggs H.D., Brill J.P., 1973, JPT 25(5), 607–617, ур. 1–25, Table 1 — основная корреляция.
- Payne G.A., Palmer C.L., Brill J.P., 1979, JPT 31(9), 1198–1208 — поправка на holdup.
- Brill J.P., Mukherjee H., «Multiphase Flow in Wells», 1999, ур. 4.110–4.119 — уточнённая
  карта режимов (флаг `revised_map`).

## Режимы

SEGREGATED, INTERMITTENT, DISTRIBUTED; при `revised_map` добавляется TRANSITION. Режим не зависит
от угла: карта построена для горизонтали (см. [модель `beggs_brill_map`](../06-flow-patterns/beggs-brill-map.md)).
Другие модели режима с этой корреляцией не совместимы.

## Схема расчёта

1. Безразмерные величины: λ_L = v_sl/v_m, число Фруда N_FR = v_m²/(g·d), скоростное число
   жидкости N_Lv, свойства смеси без проскальзывания (ρ_ns, μ_ns, Re_ns).
2. Режим — по карте `beggs_brill_map`.
3. Истинное содержание жидкости на горизонтали: H_L(0) = A·λ^α/N_FR^|β| (Table 1, ур. 19–21), не
   ниже λ.
4. Коэффициент наклона C: для подъёма зависит от режима (ур. 22–24, для DISTRIBUTED C = 0), для
   спуска одна формула (ур. 25); на горизонтали ψ = 1.
5. Поправка на наклон: ψ = 1 + C·[sin φ − sin³φ/3], φ = 1.8·θ°; H_L(θ) = H_L(0)·ψ, в пределах
   0…1. В зоне TRANSITION holdup — линейная интерполяция между SEGREGATED и INTERMITTENT.
6. Коэффициент трения двухфазного потока: f_tp = f_ns·e^S, где S — функция y = λ/H_L² (ур. 16);
   в узкой зоне 1 < y < 1.2 используется отдельная формула.
7. f_ns — гладкая формула (13) или Colebrook (флаг `rough_pipe_friction`).
8. Градиент давления: −dp/dL = [ρ_s·g·sinθ + f_tp·ρ_ns·v_m²/(2d)]/(1 − Ek), где
   Ek = ρ_s·v_m·v_sg/p (ур. 1).

## Составляющие результата

Гравитационная и фрикционная части считаются по числителю ур. 1; составляющая ускорения — разность
между полным градиентом и их суммой (проявляется делением на 1 − Ek).

## Флаги

Полная таблица — в [README проекта](../../../README.md).

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `revised_map` | `False` | Карта L1–L4 с зоной TRANSITION вместо оригинальной карты; убирает скачок H_L на границе segregated/intermittent |
| `payne_correction` | `False` | Поправка Payne: H_L × 0.924 при подъёме (не ниже λ), × 0.685 при спуске |
| `rough_pipe_friction` | `False` | f_ns по Colebrook с шероховатостью вместо гладкой формулы (13) |
| `clip_negative_c` | `False` | C < 0 заменяется на 0 (ψ ≥ 1 при подъёме) |
| `include_acceleration` | `True` | Знаменатель 1 − Ek в ур. 1; выключается для сверки с примерами монографии и при Ek → 1 |

## Расхождения с источником и допущения

- Таблица 4.2 монографии содержит a = 0.855 для INTERMITTENT; принято a = 0.845 как в оригинальной
  статье (исправление опечатки).
- При Re_ns < 2000 принимается f_ns = 64/Re в обоих режимах трения.
- Поправка Payne: множитель 0.924 при θ > 0 с нижней границей λ, 0.685 при θ < 0 без границы.

## Ограничения и ошибки

- При Ek ≥ 1 (газ высокой скорости при малом давлении) знаменатель 1 − Ek не положителен —
  возникает `ConvergenceError`. Выключите `include_acceleration` либо проверьте входные данные.
- Режим вне набора SEGREGATED / INTERMITTENT / DISTRIBUTED / TRANSITION — `UnsupportedPatternError`.
