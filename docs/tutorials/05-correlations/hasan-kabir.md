# Корреляция Hasan–Kabir (`hasan_kabir`)

Механистическая корреляция для вертикального подъёма газожидкостной смеси в трубе и в затрубном
пространстве. Для каждого режима используется модель дрейфа газа.

## Источник

Hasan A.R., Kabir C.S., 1988, SPE Production Engineering 3(2), 263–272 (с Erratum 1989), ур.
(1)–(42). Для режимов см. [модель `hasan_kabir_fp`](../06-flow-patterns/hasan-kabir-fp.md).

## Область применения

Только вертикальный подъём (θ = 90°). При любом другом угле расчёт выполняется (гравитация
считается с sinθ), но выдаётся `OutOfRangeWarning`. Поддерживаются труба (`d_t_m = 0`) и затрубье
(`d_t_m > 0`): `r = d_t/d`.

## Режимы

BUBBLE, DISPERSED_BUBBLE, SLUG, CHURN, ANNULAR. Родная модель режима — `hasan_kabir_fp`.

## Схема расчёта

Истинное газосодержание f_g определяется моделью дрейфа, истинное содержание жидкости
H_L = 1 − f_g (кроме кольцевого режима).

- **BUBBLE / DISPERSED_BUBBLE.** f_g = v_gs/(C0·v_M + v∞), C0 = 1.2 + 0.371·r (ур. 16–19);
  плотность смеси ρ_M = ρ_g·f_g + ρ_L·(1 − f_g); трение по Moody для Re = ρ_L·v_M·d/μ_L.
- **SLUG.** f_g = v_gs/(C1·v_M + v∞T). Труба: C1 = 1.2, скорость подъёма пузыря Тейлора
  v∞T = C2·√(g·d·Δρ/ρ_L), C2 = 0.345. Затрубье: C1 = 1.182 + 0.90·r и
  v∞T = (0.30 + 0.22·r)·√(g·(d − d_t)·Δρ/ρ_L). Трение: f·ρ_L·(1 − f_g)·v_M²/(2d).
- **CHURN.** Как SLUG, но C1 = 1.15 + 0.90·r.
- **ANNULAR.** Критическая скорость капель (34), доля уноса E (35)/(36), плотность ядра ρ_c,
  газосодержание f_g = (1 + X^0.8)^−0.378, коэффициент трения ядра по Fanning
  f_c = 0.079·Re_g^−0.25·[1 + 75·(1 − f_g)]. Градиент:
  −dp/dL = [ρ_c·g·sinθ + 2·f_c·ρ_c·v_g²/d]/(1 − ρ_c·v_g²/p). H_L = (1 − f_g) + f_g·(1 − f_gc).

## Расхождения с источником и допущения

Опечатки статьи исправлены по Erratum и по ТЗ: в ур. (6) ρ_M заменено на ρ_L, в (23)
exp((3.37 − N_Eo)/m), в (26b) N_f^−0.35, в (30) g·(d_c − d_t), в (37b) E·v_Ls.

Допущения:

- Ускорение (знаменатель 1 − Ek) учитывается только в кольцевом режиме (ур. 33); в остальных
  режимах оно пренебрегается, как в статье.
- Диаметр в расчёте трения для затрубья — d; эквивалентный d_c − d_t используется только в
  скорости пузыря Тейлора v∞T.

## Ограничение: сухой газ

При v_sl → 0 (но не равном нулю) корреляция остаётся в режимах SLUG/CHURN, где газосодержание
ограничено моделью дрейфа (f_g не выше ≈ 0.85), и не стремится к однофазному газу; градиент может
в десятки раз превышать газовый. Подробности — в [общем разделе](README.md#ограничение-предел-сухого-газа-v_sl--0).

## Предупреждения и ошибки

- `OutOfRangeWarning` при θ ≠ 90°. Текст сообщения постоянный (без значения угла), поэтому
  стандартный фильтр Python показывает его один раз на место вызова даже при меняющемся угле в
  профиле скважины; значение угла лежит в атрибуте `context["theta_deg"]`. Полностью отключить
  предупреждение можно флагом `warn_non_vertical=False` (результат не меняется).
- `OutOfRangeWarning`: число Рейнольдса плёнки меньше 3000 — корреляция Steen–Wallis вне области
  применимости.
- `UnsupportedPatternError` для режимов вне перечня (например, STRATIFIED).
- Ek ≥ 1 в кольцевом режиме — `ConvergenceError`.
