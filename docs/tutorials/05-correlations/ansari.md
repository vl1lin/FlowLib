# Корреляция Ansari (`ansari`)

Механистическая комплексная модель для подъёма газожидкостной смеси в скважине: отдельные модели
для пузырькового, пробкового и кольцевого режимов.

## Источник

Ansari A.M., Sylvester N.D., Sarica C., Shoham O., Brill J.P., 1994, SPE Production &
Facilities 9(2), 145–152, ур. (1)–(102). Режимы — [модель `ansari_fp`](../06-flow-patterns/ansari-fp.md).

## Область применения

Подъём (вертикальный и наклонный). Расчёт при отрицательных углах выполняется, но находится вне
области применимости статьи.

## Режимы

BUBBLE, DISPERSED_BUBBLE, SLUG, ANNULAR; режим CHURN считается как SLUG (по Ansari churn входит в
slug). Родная модель режима — `ansari_fp`.

## Схема расчёта

- **BUBBLE.** H_L — из уравнения скорости подъёма пузырей (22):
  1.53·[g·σ·Δρ/ρ_L²]^0.25·H_L^0.5 = v_sg/(1 − H_L) − 1.2·v_m. Плотность и вязкость смеси по H_L,
  градиент: гравитация плюс трение по Moody; ускорение не учитывается.
- **DISPERSED_BUBBLE.** То же при H_L = λ_L (без проскальзывания).
- **SLUG.** Решение пробковой ячейки (ур. 29–43): скорость пузыря Тейлора, содержание газа в
  пробке, скорости фаз и содержание жидкости в газовом пузыре H_LTB (корень ур. 39), доля пузыря β,
  длины пробки L_LS = 30·d и пузыря L_TB. Если длина развития плёнки L_c не меньше L_TB, пробка
  считается **развивающейся**: используются L_TB*, β*, H_LTBA (ур. 54–57, 64). Градиент —
  гравитация (60) или (62) плюс трение пробки (65); ускорение не учитывается.
  H_L = (1 − β)·H_LLS + β·H_LTB (для развивающейся — с β* и H_LTBA).
- **ANNULAR.** Решение для толщины плёнки δ (ур. 96), коэффициент φ_C² = Z/(1 − 2δ)^5 (99),
  градиент −dp/dL = φ_C²·(dp/dL)_SC + ρ_C·g·sinθ (102);
  H_L = 4δ(1 − δ) + λ_LC·(1 − 2δ)².

## Расхождения с источником и допущения

Исправления опечаток по ТЗ: ур. (18) v_TP = v_m; (32) v_TB; (40) Ā = H_gLS·(v_TB − v_gLS) + v_m
(буквальная форма — флаг `vo_shoham_a_as_published`); (85) (ρ_L/ρ_g)^(1/3).

Расхождение сверх таблицы опечаток: в ур. (56) напечатано b с множителем (2 − H_LLS); для набора R2
это даёт отрицательный подкоренной дискриминант (54) и комплексные корни. Из (52)–(53) следует
множитель (1 − H_LLS); он принят по умолчанию. Напечатанный вариант включается флагом
`eq56_as_published` — тогда развивающаяся пробка для R2 не определяется и расчёт переходит на
полностью развитую пробку. Влияние на R2: −dp/dL 5178 Па/м (по умолчанию) против 4912 Па/м.

Ур. (54) получено возведением в квадрат, поэтому берётся больший положительный корень.

Допущение: v_NLTB в ур. (45) определяется из баланса (32) с H_NLTB (46).

## Ограничение: сухой газ

При v_sl → 0 (но не равном нулю) корреляция не стремится к однофазному газу: пробковая модель
ограничивает долю газового пузыря (градиент в десятки раз выше газового). При высоком давлении
режим ANNULAR может давать толстую плёнку: критерий перемыкания (12) по оригинальной статье
вычисляется по δ_min из ур. (8), (11), а градиент — по δ из ур. (96). Подробности — в
[общем разделе](README.md#ограничение-предел-сухого-газа-v_sl--0).

## Ограничения и ошибки

- `UnsupportedPatternError` для режимов вне перечня (STRATIFIED_*, ELONGATED_BUBBLE и др.).
- `ConvergenceError`: не найдена толщина плёнки Нуссельта (45)–(46) в пробковой ячейке.
- Результаты в `details` содержат промежуточные величины ячейки (v_TB, H_gLS, H_LTB, β, L_TB, L_c,
  признак `developing` и др.); для кольцевого режима — F_E, λ_LC, δ, X_M², Y_M, Z, φ_C².
