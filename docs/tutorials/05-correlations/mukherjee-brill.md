# Корреляция Mukherjee–Brill (`mukherjee_brill`)

Эмпирическая корреляция для наклонных труб: восходящих и нисходящих. В отличие от Beggs–Brill
учитывает расслоённый режим при спуске и отдельно считает истинное содержание жидкости для каждой
группы режимов.

## Источники

- Mukherjee H., Brill J.P., 1985, J. Energy Resources Technology 107(4), 549–554, ур. (1)–(27),
  Table 1–2 — корреляция.
- Mukherjee H., Brill J.P., 1985, Int. J. Multiphase Flow 11(3), 299–315 — режимы потока.

## Режимы

BUBBLE, SLUG, ANNULAR, STRATIFIED. Другие режимы вызывают `UnsupportedPatternError`. Родная
модель режима — [`mukherjee_brill_fp`](../06-flow-patterns/mukherjee-brill-fp.md).

## Схема расчёта

1. Безразмерные числа: скоростные числа жидкости N_Lv и газа N_gv, число свойств жидкости N_L
   (с ускорением свободного падения).
2. Режим — по карте `mukherjee_brill_fp`.
3. Истинное содержание жидкости H_L — по ур. (10) и коэффициентам Table 1: для подъёма и
   горизонтали — набор «uphill and horizontal»; для спуска расслоённого режима — набор «downhill
   stratified»; для спуска остальных режимов — «downhill other».
4. Градиент давления зависит от режима:
   - BUBBLE и SLUG: −dp/dL = [f_ns·ρ_s·v_m²/(2d) + ρ_s·g·sinθ]/(1 − Ek), где f_ns — по Moody
     (Colebrook) для числа Рейнольдса без проскальзывания, Ek = ρ_s·v_m·v_sg/p.
   - ANNULAR: коэффициент трения f = f_R·f_ns, f_R — по Table 2 как функция H_R = λ/H_L
     (вне диапазона 0.01…10 принимается 1), затем та же схема с делением на 1 − Ek.
   - STRATIFIED: геометрия расслоённого потока (угол смачивания δ из H_L, эквивалентные диаметры
     фаз, периметр газа), трение каждой фазы по Moody, касательное напряжение τ_w = f·ρ·v²/8,
     градиент по касательному напряжению газа плюс гравитация газа (ур. 15 при τ_i = 0).
     Ускорение равно нулю.

## Флаги

Полная таблица — в [README проекта](../../../README.md).

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `include_acceleration` | `True` | Знаменатель 1 − Ek в BUBBLE / SLUG / ANNULAR |
| `stratified_combined_momentum` | `False` | Для расслоённого потока уравнение (17) (сумма фаз, без τ_i) вместо (15); рекомендация авторов для труб большого диаметра |
| `wall_shear_as_published` | `False` | τ_w = f·ρ·v²/2 «как напечатано» вместо f·ρ·v²/8; только для воспроизведения буквально реализованного кода |
| `annular_fr_log_interp` | `False` | Интерполяция Table 2 по lg H_R вместо линейной по H_R |

## Расхождения с источником и допущения

- Число N_L определяется с учётом g (в статье JERT напечатано без g).
- Ур. (10) записано в общепринятой форме скобок; в монографии формула (4.135) содержит sin³θ
  вместо sin²θ — принято sin²θ.
- В расслоённой ветви относительная шероховатость фазы принята как ε/D_E (эквивалентный диаметр
  фазы).
- H_L ограничивается сверху единицей: формула (10) может дать значение больше 1 при больших N_L.

## Ограничения и ошибки

- Режим вне BUBBLE / SLUG / ANNULAR / STRATIFIED — `UnsupportedPatternError`. Поэтому корреляция
  не работает с картами, выдающими STRATIFIED_SMOOTH / STRATIFIED_WAVY (Barnea, Taitel–Dukler).
- Ek ≥ 1 — `ConvergenceError` (см. [общий раздел](README.md)).
