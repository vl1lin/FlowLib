# Сверка с симуляторами: данные и требования к моделям

Файлы каталога:

| Файл | Назначение |
|---|---|
| `cases.csv` | 193 расчётных случая: входные данные для `FlowState` (СИ). Результатов библиотеки в файле нет |
| `results_template.csv` | Пустой шаблон для результатов симуляторов (по одной строке на случай × программу × модель) |
| `simulator-requirements.md` | Этот файл: как настраивать модели в PIPESIM и OLGA-S |

CSV сохранены в UTF-8 с BOM, разделитель — запятая. В Excel: «Данные → Из текста/CSV», разделитель
«запятая». Десятичная точка, числа в научной нотации (`1.6e-05`).

## Как пользоваться таблицей случаев

Библиотека **не строит карты режимов**: в ней нет ни модуля построения карт, ни графики. Каждый
случай — отдельная точка, для которой модель режима (`predict`) выдаёт один режим. Группа C — это
сетка таких точек: сравнивается режим в каждой точке, а график (если нужен) собирается вне
библиотеки по результатам.

Поле `priority`: 1 — обязательные (14 случаев), 2 — основные (141), 3 — по возможности (38).
Начните с приоритета 1, затем добавляйте группы:

| Группа | Что проверяет | Случаев |
|---|---|---|
| A | Вертикальный подъём R1/R2 из ТЗ: базовые точки и развёртки по v_sl, v_sg, шероховатости, углу | 23 |
| B | Затрубье (Hasan–Kabir) | 4 |
| C | Сетка точек воздух–вода для сравнения режимов, d = 0.0508 м, горизонталь и вертикаль (5 × 6) | 60 |
| D | Наклонные трубы воздух–вода, углы +5°, +30°, +60°, −5°, −30°, −80° (сетка 3 × 3) | 54 |
| E | Критерий Barnea [14] (флаг `friction_ratio_as_published`), нисходящий поток | 5 |
| F | Малый диаметр d = 0.0254 м, углы 0°, 90°, −80° | 27 |
| G | Предел сухого газа (v_sl → 0) | 9 |
| H | Большая скорость газа при малом давлении (слагаемое ускорения) | 4 |
| I | Шероховатость стенки, воздух–вода | 4 |
| J | Вязкая жидкость (флаг `wallis_c2`) | 3 |

Столбцы `cases.csv`: `case_id`, `group`, `priority`, `purpose`, `fluid_set` (R1, R2, AW — наборы из
ТЗ), `v_sl_m_s`, `v_sg_m_s`, `rho_l_kg_m3`, `rho_g_kg_m3`, `mu_l_pa_s`, `mu_g_pa_s`, `sigma_n_m`,
`d_m`, `d_t_m`, `eps_m`, `theta_deg`, `p_pa`, `notes`. Значения — целевые; фактические значения
берутся из отчёта симулятора и записываются в `results_template.csv` (поля `*_actual`, `rho_*`,
`mu_*` и т.д.). Именно фактические значения затем подставляются в `FlowState` библиотеки.

## Общие требования к настройке (обе программы)

1. **Постановка.** Стационарный расчёт, изотермический (теплообмен отключён), без механического
   оборудования, фитингов и переходов.
2. **Участок.** Одна труба постоянного диаметра, угла и шероховатости, длиной 1–10 м. Короткий
   участок нужен, чтобы свойства флюида и скорости внутри него не менялись, а градиент можно было
   брать как Δp/L.
3. **Флюид.** Две фазы: газ и одна жидкость (нефть для R1/R2, вода для AW), без эмульсий,
   гидратов, твёрдых частиц и массообмена между фазами. Если используется модель чёрной нефти, подберите
   давление и температуру так, чтобы доля растворённого газа не менялась по участку.
4. **Направление и угол.** Угол отсчитывается от горизонтали; положительный — подъём. Запишите, как
   знак угла и направление потока задаются в программе (в PIPESIM — подъём/спуск по направлению
   потока).
5. **Выходные величины в точке (на каждый случай):**
   - режим течения (название в программе);
   - истинное содержание жидкости (holdup, in situ);
   - приведённые скорости жидкости и газа, скорость смеси;
   - плотности и вязкости фаз, поверхностное натяжение, давление, температура;
   - полный градиент давления и его составляющие: гравитационная, трения, ускорения (если
     доступны);
   - для OLGA-S дополнительно, если выдаётся: толщина или доля плёнки, длина пробки.
6. **Точность вывода.** Не менее 4 значащих цифр, единицы СИ (или запишите единицы).
7. **Воспроизводимость.** Сохраните файл проекта, запишите версию программы, версию модуля
   многофазных корреляций и настройки (снимок экрана). Один случай — одна запись в
   `results_template.csv` (колонки `software`, `software_version`, `model_or_correlation`,
   `model_settings`).
8. **Сообщения программы.** Если программа выдаёт предупреждение «вне области применимости»,
   «критическое течение» или не поддерживает режим, запишите это в `comment`.
9. **Что не подгонять.** Настройки корреляции не меняйте ради совпадения с библиотекой.
   Расхождения фиксируются как есть: цель — найти ошибки и классифицировать флаги, а не добиться
   совпадения.

## Требования к моделям в PIPESIM

Для каждой модели повторите приоритетные случаи и запишите настройки:

| Модель библиотеки | Модель в PIPESIM для сверки | Что зафиксировать |
|---|---|---|
| `beggs_brill` | Beggs and Brill, варианты Original и Revised | Поправка на holdup (Payne), модель трения (гладкая труба или Moody), ограничение C ≥ 0 |
| `mukherjee_brill` | Mukherjee and Brill | Модель трения, поведение для нисходящего потока |
| `hasan_kabir` | Hasan and Kabir (если есть в версии) | Вертикальная труба и затрубье, поправки для пузырьков |
| `ansari` | Ansari / TUFFP (если есть в версии) | Учёт развивающейся пробки, режимы кольцевой/пробковый |
| `barnea`, `taitel_dukler` | Унифицированная модель (Tulsa/TUFFP unified) или OLGAS | Критерии выбора режима, модель трения |

Для всех: отключить корректирующие множители holdup и трения (принять равными 1.0), записать
параметры по умолчанию (шероховатость, модель вязкости, модель плотности смеси), записать, как
программа определяет режим течения (по какому критерию). Состав доступных корреляций зависит от
версии PIPESIM — уточните у преподавателя.

## Требования к OLGA-S

OLGA-S (стационарная механистическая модель) не повторяет ни одну из четырёх корреляций точно,
поэтому её используют как независимый ориентир:

- сравнивать в первую очередь режим течения и тренды (зависимость градиента и holdup от v_sl, v_sg,
  угла), а не абсолютные значения;
- ожидаемое совпадение градиента при одинаковом режиме — порядка 10–20%; при разных режимах
  сравнивать отдельно;
- использовать для групп C, D, E и G (режимы по сетке точек, критерий Barnea [14], предел сухого газа);
- записать версию модуля, модель режима, модель трения и опции пробкового потока.

## Что считать результатом сверки

Для каждого случая сравниваются: режим, holdup, полный градиент и составляющие. Расхождения
классифицируются:

| Класс | Признак | Что делать |
|---|---|---|
| Совпадение | Режим тот же, градиент и holdup в пределах допуска | Эталон подтверждён; убрать пометку `provisional` |
| Различие моделей | Режим тот же, расхождение систематическое (например, другая модель трения) | Описать, подобрать флаг библиотеки, если он есть; не менять формулы |
| Различие режима | Режимы разные | Сравнить критерии перехода с оригинальной статьёй; возможна граница между режимами |
| Подозрение на ошибку | Расхождение в разы или противоречие с оригинальной статьёй | Проверить реализацию и формулу по статье, сообщить |

Допуски по умолчанию (предварительные, уточнить с преподавателем): градиент 10% при совпадении
режима; holdup 0.05 по абсолютной величине.
